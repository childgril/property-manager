# 不動產資產管理系統

個人不動產資產管理工具。涵蓋**權狀**（土地/建物）、**不動產物件**、**買賣交易（含金流）**、**銀行借貸（含繳款）**。

> 採權狀優先設計：權狀是最底層獨立個體，組成物件後再進行買賣、借貸。

## ✨ 特色

- **權狀優先設計**：土地、建物各自獨立，各有生命週期（取得 → 持有 → 處分）
- **完全本機**：資料只存在你的電腦，不經過任何伺服器
- **零安裝**：雙擊 `index.html` 即可使用，不需要 Node、Python 或任何環境
- **真資料庫**：底層用 SQLite，資料可匯出成 `.db` 檔保存與備份

## 🔒 資料安全（重要）

**你的權狀資料永遠不會被上傳到 GitHub。**

- 程式碼（這個 repo）放 GitHub，方便版本管理
- 資料（`.db` 檔）只存你本機，已被 `.gitignore` 排除，不會被 commit
- 請定期用「💾 儲存到檔案」匯出 `.db` 備份到安全的地方（例如加密隨身碟）

⚠️ 不要把匯出的 `.db` 檔放進這個資料夾後 commit。`.gitignore` 已盡量防範，但仍請留意。

## 🚀 使用方式

### 方法一：直接開啟（最簡單）
1. 下載整個資料夾（或 `git clone`）
2. 雙擊 `index.html`，用瀏覽器開啟
3. 首次開啟會自動下載 SQLite 引擎（需網路，約數秒），之後就能離線用

### 方法二：本機伺服器（可選，更穩定）
```bash
# 在資料夾內執行（擇一）
python3 -m http.server 8000
# 然後瀏覽器開 http://localhost:8000
```

## 📖 操作說明

1. **第一次使用**：點左下角「🌱 載入範例資料」看看系統怎麼運作
2. **新增權狀**：到「土地權狀」或「建物權狀」頁，點「+ 新增」
3. **查看生命週期**：點任一筆權狀進入明細頁，可新增生命週期事件（取得、設定抵押、改良、處分等）
4. **儲存資料**：點「💾 儲存到檔案」匯出 `.db` 檔。**這是你的正式備份。**
5. **載入資料**：換電腦或重開後，點「📂 載入 .db 檔」把之前匯出的檔案讀回來

> 系統會在瀏覽器暫存資料（localStorage），但那只是方便，**正式備份請務必用「儲存到檔案」**。清除瀏覽器資料會刪掉暫存。

## 🗂️ 檔案結構

```
property-manager/
├── index.html    # 主頁面與樣式
├── app.js        # 資料庫、總覽、權狀列表
├── forms.js      # 權狀表單、明細頁、範例資料
├── modules.js    # 物件、買賣交易(金流)、銀行借貸(繳款)
├── .gitignore    # 保護資料檔不被上傳
└── README.md     # 本說明
```
